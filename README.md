- https://bbs-game.aridjaya.eu.org
- https://bbs-paint-board.aridjaya.eu.org

Official sites:

- https://site-game.aridjaya.eu.org
- https://site-paint-board.aridjaya.eu.org

## Categories (defaults — rename in UI if you like)

| Category | Used for |
|---|---|
| Announcements | Giscus page comments — **game** site (`site-game`) |
| Show and tell | Giscus page comments — **paint** site (`site-paint-board`) |
| General | Cross-project / intros (rename to Studio optional) |
| Ideas / Q&A / Polls | Free chat — rename to Project Turn / Paint Board as needed |

Giscus uses `mapping: url` so game and paint paths do not collide.

1. Install the [giscus GitHub App](https://github.com/apps/giscus) on **this** repository only.
2. Official site configs live in `liuyuliangbox/official-sites` → `src/lines/*.ts`.
